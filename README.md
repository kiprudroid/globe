# Globe

Interactive 3D Earth globe built with Next.js and Three.js. Rotatable, zoomable, and geographically accurate using NASA Blue Marble imagery.

## Tech Stack

- Next.js (App Router)
- Three.js via `@react-three/fiber`
- Tailwind CSS

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Texture Sources

Earth textures from [Solar System Scope](https://www.solarsystemscope.com/textures/) (CC BY 4.0), based on NASA Blue Marble data. See `public/textures/earth/README.md` for details.
